# Untuk Bee, dengan sayang ♡

Website statis: HTML, CSS, JavaScript. Semua 12 foto dan ilustrasi sudah disertakan.
Tidak memerlukan npm, database, atau proses build.

## Upload lewat browser
1. Ekstrak ZIP ini.
2. Buat repository GitHub bernama untuk-bee. Untuk GitHub Free, pilih Public.
3. Di repository, pilih Add file > Upload files.
4. Upload isi folder hasil ekstrak: index.html, style.css, app.js, folder assets, dan file pendamping.
   Jangan upload ZIP-nya. Pastikan index.html berada di root repository, bukan di subfolder.
5. Commit changes.
6. Buka Settings > Pages.
7. Pilih Source: Deploy from a branch; Branch: main; Folder: / (root); Save.
8. Tunggu proses selesai. Alamat tampil di Settings > Pages.
   Pola alamat: https://USERNAME.github.io/untuk-bee/

Panduan resmi:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Musik
Honeybee — Olivia Rodrigo dipasang lewat pemutar YouTube; berkas audio tidak disertakan.
Website mencoba memulai musik saat tombol Buka, sayang disentuh.
Browser, koneksi internet, dan izin embed video dapat membatasi pemutaran.
Jika tertahan, gunakan Lagu kita atau pemutar YouTube pada halaman.
Font online memakai Google Fonts, dengan font bawaan sebagai pengganti.

## Mengubah isi
- index.html: judul, nama, ucapan.
- style.css: warna, tipografi, dan tata letak.
- app.js: urutan foto, keterangan, pesan bunga, serta ID video YouTube.
- assets/: foto dan ilustrasi.
